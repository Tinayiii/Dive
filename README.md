# Dive

Dive 是一个以真实见面为核心的 Dating 活动产品原型。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可体验移动端流程模拟。

## 覆盖流程

- Dating Plan 与活动广场卡片浏览
- Save / No / Apply / Lock fee / Invite
- 我的活动、Host 申请管理与活动修改
- Profile、活动上下文 IM、活动结束后的反馈
- 单人 Date 与 Small Date 的七步创建流程

## 构建

```bash
npm run build
```
